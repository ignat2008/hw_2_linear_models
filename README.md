# Логистическая регрессия с нуля: градиентный спуск, SGD и elastic net

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/ignat2008/hw_2_linear_models/blob/main/logistic_regression_sgd.ipynb)

Линейные алгоритмы на уровне численных методов: от градиентного спуска на простой функции до собственной логистической регрессии с $l_1$- и $l_2$-регуляризацией.

> **Статус проекта: заготовка.** Ключевые участки кода в ноутбуке пока не дописаны и помечены `YOUR CODE` / `<YOUR CODE>`: шаг градиентного спуска, генератор батчей, `fit` и `get_grad`, лосс и градиент elastic net, итоговый pipeline. Поэтому ноутбук целиком не запускается и результатов обучения в репозитории нет. Ячейки с `assert` показывают, какие значения должны получиться.

## Содержание ноутбука

1. **Градиентный спуск** для $f(x, y) = \sin^2 x + \sin^2 y$: аналитический градиент $\nabla f = (\sin 2x, \sin 2y)$, цикл спуска, визуализация траектории на 3D-графике (plotly и matplotlib) и график значения функции по шагам.
2. **Генератор батчей**: перемешивание через `np.random.permutation`, неполный последний батч отбрасывается.
3. **`MyLogisticRegression`**: логистическая регрессия, обучаемая SGD. Функция потерь

   $$Loss(y, p) = -\sum_{i=1}^{\ell} \big(y_i \log p_i + (1 - y_i) \log (1 - p_i)\big),$$

   градиент $\dfrac{\partial L}{\partial w} = X^T (p - y)$.
4. **`MyElasticLogisticRegression`**: наследник с $l_1$- и $l_2$-регуляризацией (bias в регуляризацию не входит).
5. **Проверка модели** на синтетических данных (`make_blobs`) и на цифрах MNIST (классы 0 и 1) с кросс-валидацией.

## Как запустить

```bash
pip install -r requirements.txt
jupyter notebook logistic_regression_sgd.ipynb
```

Для блока с MNIST нужен файл `train.csv` (MNIST в формате CSV: метка и 784 пикселя в строке). В репозиторий он не включён, положите его рядом с ноутбуком.
